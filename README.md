# Collections of HTML, CSS, & JS Projects 🌐

> **⚠️ LEGACY REPOSITORY:** This repository contains a collection of older web development projects completed in the past. It serves as an archive of my earlier front-end work, learning progress, and experiments with vanilla HTML, CSS, and JavaScript. It is no longer actively maintained or updated.

## 📖 About
This repository holds a variety of interactive web components, mini-apps, and UI features built strictly using core web technologies (HTML, CSS, and vanilla JavaScript). It highlights fundamental DOM manipulation, styling, and browser APIs.

## 📂 Project List
Here is a list of the folders and projects included in this collection:

* **animated-counter-app:** A number counter with a smooth counting animation.
* **digital-clock:** A real-time digital clock displaying the current time.
* **drum-on-browser:** An interactive virtual drum kit that can be played using the keyboard.
* **fibonacci-sequence-generator:** A tool that calculates and displays the Fibonacci sequence.
* **hsl-color-generator:** A color manipulation tool using HSL values.
* **image-comparison-slider:** A slider component to visually compare "before" and "after" images.
* **infinite-carousel:** An endlessly scrolling image or content carousel.
* **loading-screen:** A custom CSS/JS loading animation or spinner screen.
* **modal-app:** A standard popup modal window UI component.
* **piano-app:** A playable browser-based piano keyboard.
* **play-dice-on-browser:** A simple random dice rolling game.
* **robot-joke-generator:** An app that fetches and displays random jokes.
* **search-functionality-app:** A UI component demonstrating real-time list filtering/searching.
* **speech-to-text-app:** An application that uses the Web Speech API to dictate voice into text.
* **star-rating-app:** An interactive 5-star rating UI component.
* **switch-button:** A stylized toggle/switch button component.
* **text-to-speech-app:** An application that reads typed text out loud.
* **the-simon-game:** A web-based clone of the classic memory game "Simon".
* **typing-text-effect-app:** A component that creates a visual typewriter effect.

## 🚀 How to Run
Since these are purely frontend vanilla web projects, they don't require complex build steps or servers to run.

1. Clone the repository:
   ```bash
   git clone [https://github.com/ziqkimi308/collections-of-projects-html-css-js-.git](https://github.com/ziqkimi308/collections-of-projects-html-css-js-.git)
   ```

2. Navigate into the specific project folder you want to view.
3. Simply double-click the `index.html` file to open it directly in your web browser.
